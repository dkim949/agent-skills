# Progressive learning

Use only for an explicit request for a learning sequence, guided practice, exercises, or quizzes. Match the requested scope: a single exercise needs no course setup.

1. Use the user's stated goal and experience to choose one manageable next step. Ask a focused question only if that information would materially change the lesson.
2. Explain the minimum knowledge needed and show a worked example grounded in reliable material or the actual code.
3. When practice is requested, offer a closely related task with a clear expected outcome. When a quiz is requested, make choices plausible and avoid formatting clues.
4. Give specific feedback on the submitted attempt, then explain the gap or next step. Use a later variation or recall exercise when the user wants continued practice.

Keep progress in the current conversation. Create lessons, records, folders, reference sheets, or persistent preference notes only within an explicit user request for those artifacts. A request for exercises alone does not authorize a curriculum or storage workflow.
